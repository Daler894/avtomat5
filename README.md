## 4. Часть 2. Метод рекурсивного спуска

### 4.1. Лексемы

| Лексема | Вид | Пример |
|---|---|---|
| `i` | имя переменной: 1–2 латинские буквы | `a`, `ab` |
| `n` | десятичная константа | `123` |
| `b` | двоичная константа с префиксом `#b` | `#b1011` |
| `p` | пятеричная константа с префиксом `#p` | `#p1342` |
| `&` `^` `\|` | бинарные операции | |
| `~` | унарная операция | |
| `( )` | скобки | |
| `=` | присваивание | |
| `;` | разделитель операторов | перевод строки эквивалентен `;` |

Лексемы распознаются регулярными выражениями (`#b[01]+`, `#p[0-4]+`, `[0-9]+`, `[A-Za-z]{1,2}(?![A-Za-z])`, `[&^|~()=;]`). Цепочка вида `#b1012` разбивается на лексемы `#b101` и `2`, поэтому отвергается.

### 4.2. Грамматика

Начальный символ: `P`. Нетерминалы и терминалы записаны в виде классов лексем.

```
 1. P -> S L
 2. L -> ; S L
 3. L -> ε
 4. S -> i = E
 5. E -> U R
 6. R -> O U R
 7. R -> ε
 8. O -> &
 9. O -> ^
10. O -> |
11. U -> ~ U
12. U -> A
13. A -> n
14. A -> b
15. A -> p
16. A -> i
17. A -> ( E )
```

Ассоциативность бинарных операций правая (как и в части 1).

### 4.3. Множества FIRST и FOLLOW

| Нетерминал | FIRST | FOLLOW |
|---|---|---|
| P | {i} | {$} |
| S | {i} | {$, ;} |
| L | {;, ε} | {$} |
| E | {~, n, b, p, i, (} | {$, ), ;} |
| R | {&, ^, \|, ε} | {$, ), ;} |
| O | {&, ^, \|} | {~, n, b, p, i, (} |
| U | {~, n, b, p, i, (} | {$, &, ^, \|, ), ;} |
| A | {n, b, p, i, (} | {$, &, ^, \|, ), ;} |

### 4.4. Формальное доказательство принадлежности к классу LL(1)

Грамматика LL(1), если для каждого нетерминала `A` с альтернативами `α₁ | … | αₖ` выполнено:

1. `FIRST(αᵢ) ∩ FIRST(αⱼ) = ∅` при `i ≠ j`;
2. если `ε ∈ FIRST(αⱼ)`, то `FIRST(αᵢ) ∩ FOLLOW(A) = ∅` для всех `i ≠ j`.

Проверка по нетерминалам, в которых есть альтернативы:

| Нетерминал | Альтернативы | FIRST / FOLLOW | Условие |
|---|---|---|---|
| L | `; S L` и `ε` | FIRST = {;}, FOLLOW(L) = {$} | {;} ∩ {$} = ∅ |
| R | `O U R` и `ε` | FIRST = {&, ^, \|}, FOLLOW(R) = {$, ), ;} | пересечения нет |
| O | `&`, `^`, `\|` | попарно различные терминалы | пересечения нет |
| U | `~ U` и `A` | {~} и {n, b, p, i, (} | пересечения нет |
| A | `n`, `b`, `p`, `i`, `( E )` | попарно различные терминалы | пересечения нет |

Все условия выполнены для всех нетерминалов, значит грамматика является LL(1). Поскольку для каждого нетерминала выбор продукции однозначно определяется текущей лексемой, рекурсивный спуск без возвратов корректен.

**Таблица LL(1)** (номер продукции в ячейке):

| Нетерминал | Лексема → продукция |
|---|---|
| P | i → 1 |
| S | i → 4 |
| L | ; → 2; $ → 3 |
| E | ~, n, b, p, i, ( → 5 |
| R | &, ^, \| → 6; `)`, ;, $ → 7 |
| O | & → 8; ^ → 9; \| → 10 |
| U | ~ → 11; n, b, p, i, ( → 12 |
| A | n → 13; b → 14; p → 15; i → 16; ( → 17 |

### 4.5. Программа

Программа написана на Python (файл `main.py`). Каждому нетерминалу соответствует функция:

| Нетерминал | Функция |
|---|---|
| P | `parse_P` |
| S | `parse_S` |
| L | `parse_L` |
| E | `parse_E` |
| R | `parse_R` |

**Вывод:** грамматика части 3 является SLR(1).
